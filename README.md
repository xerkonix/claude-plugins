# XERKONIX plugins for Claude

## XREDY

Connect Claude to your company knowledge, datasets and entity types in [XREDY](https://xredy.com).

Install in Claude Code:

```
/plugin marketplace add xerkonix/claude-plugins
/plugin install xredy@xerkonix
```

Connection guide: https://xredy.com/docs/mcp

Contact: contact@xerkonix.com
